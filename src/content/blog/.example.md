## Formatting check

Inline `code`, **bold**, and a block:

```c
static inline uint64_t rdtsc(void) {
    uint32_t lo, hi;
    __asm__ volatile ("rdtsc" : "=a"(lo), "=d"(hi));
    return ((uint64_t)hi << 32) | lo;
}
```

> Premature optimization is the root of all evil — but measuring first is always fine.

| Level | Latency (cycles) |

| L1d   | ~4               |
| L2    | ~12              |
| L3    | ~40              |
