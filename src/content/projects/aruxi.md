## Overview

This project is a comprehensive full-stack architecture project that encompasses the development of a custom kernel, a high-level programming language, an assembly language, and a complete toolchain.

The goal of the project is to primarily learn about low-level systems and design. It additionally aims to provide a platform for experimenting with new programming paradigms and system architectures.
This stems from some dislike in how ARM, RISC-V, and x86 architectures are designed with historical baggage.
RISC-V may not contain as much baggage but in my personal opinion, it is not something intuitive.

The project's status is still under development and its early stages. The ISA is still being designed and rewritten. The kernel is incredibly simple and only able to run simple programs.
The high-level programming language is still being designed and the compiler not fully written.


To learn more about it, visit its documentation at [https://project-aruxi.github.io](https://project-aruxi.github.io).
