## Overview

This project contains a series of animations created using the MANIM library to illustrate concepts from the UT Austin CS439 Computer Architecture course. The animations cover topics such as pipelining, cache memory, and instruction execution, providing visual aids to enhance understanding of complex architectural concepts.
