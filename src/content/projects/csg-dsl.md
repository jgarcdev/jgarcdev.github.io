## Overview

This project is for a course project in Graphics. It implements a Domain Specific Language (DSL) that allows users to easily create and manipulate 3D models using Constructive Solid Geometry (CSG) techniques. The DSL is designed to be intuitive and user-friendly, enabling users to define complex shapes through simple commands.

The projecr offers both the compiler and the runtime for the DSL, allowing users to write their CSG scripts and see the results rendered in real-time using WebGPU. The project also includes a set of predefined shapes and operations, making it easy for users to get started with CSG modeling.

To learn more about the project, you can visit the [GitHub repository](https://github.com/jgarcdev/WebGPU-CSG-DSL).
