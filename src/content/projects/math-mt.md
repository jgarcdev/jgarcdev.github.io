## Overview

This project was a group project for a linguistics-based machine learning course.
The original goal of the project was to build a model that could answer high-level math questions in latex,
using special word problems as training data. However, due to time constraints and unforeseen difficulties, the project was scaled down to a model that could classify math problems into their respective topics.
